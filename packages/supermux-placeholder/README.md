# supermux

This name is held for the supermux command-line tool.

Installing it gives you a `supermux` command. Until the tool is published, the command only prints where to find the app and the library.

The library for building apps on coding agents is [`@supermux/core`](https://www.npmjs.com/package/@supermux/core).
The supermux app lives at [supermux.dev](https://supermux.dev).
