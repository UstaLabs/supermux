# supermux

This package only reserves the name `supermux` on npm. It holds no tool: its `supermux` command prints where to get the real ones and exits with status 1, so nothing takes it for the supermux CLI.

The supermux CLI installs from [supermux.dev](https://supermux.dev):

```sh
curl -fsSL https://supermux.dev/install.sh | sh
```

The library for building apps on coding agents is [`@supermux/core`](https://www.npmjs.com/package/@supermux/core):

```sh
npm i @supermux/core
```
