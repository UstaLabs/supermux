---
title: Several computers
description: Pair your laptop, a desktop and a server, and see every session from all of them in one list.
---

You can run supermux on more than one computer, for example a MacBook, a Windows PC and a Linux server, and see all of their sessions in one app.

## Add a computer

Open the sidebar's **⋮** menu and choose **Add host**, or pick **Add host…** from the host switcher. Then:

- **Scan**: scan the pairing QR code that computer shows (on a phone or tablet).
- **Paste link**: paste a pairing link from it.
- **URL**: type its address, for example `https://my-mac.tailnet.ts.net`.

Give this device a name under **This device's name**, so the other computer knows who's connecting.

<Callout title="Plain http">
To connect over plain `http` to an address outside your own computer, tick **Connect over an unencrypted connection**. Only do that on a network you trust, like your home network or a VPN.
</Callout>

## One list for everything

The **host switcher** sits at the bottom left of the sidebar. It shows:

- **All hosts**: every session from every computer, together. Each computer has its own coloured dot, and each row shows which computer it's on.
- Each computer by name, with how many sessions it's running. One that's offline is greyed out, with when it was last seen.
- **Rename** and **Forget** for each computer, and **Add host…**.

Picking a computer also decides where new sessions start and which computer **Usage** and **Settings** show. The launcher has its own computer picker too, for when you want a session somewhere else.

## Search everywhere

The **All chats** search in a chat looks through every chat on every connected computer.

## Forget a computer

**Forget** removes a computer and its sessions from this device only. Nothing changes on the computer itself. To add it back, you need a new pairing link.
