Every Agent has an animated character in the sidebar. It shows at a glance what the Agent is doing, and makes several Agents easy to tell apart.

## The ten characters

<AvatarGallery />

Pick one when you create an Agent. To change it later, right-click the Agent (or tap its **⋮**) and choose **Change character…**. Its name, memory and history stay the same.

## What the character shows

<AvatarStates name="Hoot" />

- **Idle**: the Agent is running and has nothing new for you.
- **Working**: it's busy with a turn.
- **Has a reply**: it answered and you haven't read it yet.
- **Asleep**: its session isn't running, or nothing has happened for five minutes. A sleeping Agent still answers when you write.

The character perks up when you point at it or open its chat. Two Agents with the same character never blink in step.

## Let an Agent design its own

You can ask an Agent in its chat to design an avatar for itself, for example "make yourself an avatar: a small green robot with a lantern".

It can render a preview of every state and send it to you before it saves anything. When you're happy, it saves the avatar, and every open app shows the new look right away.

An avatar is a small vector drawing with up to 150 parts and 64 KB. Only Agents have one; ordinary sessions show their agent's logo.
