Most sessions do one job and end. An Agent stays. It has a name, a character and a memory of its own, and it's always running, so you can message it whenever you like.

## Agents and ordinary sessions

| | Agent | Ordinary session |
|---|---|---|
| Lifetime | Always running. If it stops, supermux starts it again. | Stays until you archive it. If its agent stops, it wakes up on your next message. |
| Name | Yours to choose; you can rename it any time. | The agent names it after its task. You can rename it. |
| Memory | Its own memory, plus the shared one. | The shared memory. |
| Folder | Its own home folder; works on other projects when you ask. | The project it was started in. |
| Look | An animated character in the sidebar. | The agent's logo. |

Any session can start and message other sessions. A few things are kept for Agents, like creating new Agents and muting other sessions. See [Orchestration](/orchestration).

## Create an Agent

<Steps>
<Step>
### Click + next to Agents

The **Agents** section sits at the top of the sidebar, above your workspaces. On a phone, the **New Agent** form slides up from the bottom.
</Step>
<Step>
### Pick a character

Choose one of the ten characters. A preview shows how it looks while it works, has a reply, or sleeps. See [Characters and avatars](/agents-that-stay/avatars).
</Step>
<Step>
### Name it

Leave **Name** empty and the Agent takes the character's name. Picking Hoot makes an Agent called Hoot.
</Step>
<Step>
### Choose the agent and model

Pick the **Provider** (any agent you've installed), the **Model** and, where it applies, the **Effort**. They start on what you used last in the composer.
</Step>
<Step>
### Create it

Click **Create**, followed by the Agent's name. It opens with a short greeting, written in the language you usually write in.
</Step>
</Steps>

An Agent starts at its agent's most open [access level](/providers/access-levels), like any new session. You can change it in the composer.

## Manage an Agent

Right-click an Agent in the sidebar, or tap its **⋮** on a phone:

- **Rename…**: its memory and history stay with it.
- **Change character…**: pick another look.
- **Make default**: see below.
- **Mute** / **Unmute**: stop or resume its notifications.
- **Mark as read**
- **Archive…**: it stops running and leaves the sidebar.

Drag Agents up and down to put them in the order you like.

A quiet Agent is drawn asleep after five minutes. It's still running and answers as soon as you write.

## Archive and restore

Archiving keeps everything: its memory, character and conversation. Archived Agents wait in an **Archived** fold under the Agents. Click **Restore** to bring one back exactly as it was.

## The default Agent

Your first Agent becomes the default. supermux sends a message to the default Agent when it has no session to go to. In the app every Agent has its own chat, so you'll rarely notice which one it is. **Make default** changes it.

## Talking to your Agent

An Agent is a normal chat. Open it from the sidebar and type, or use [voice](/sessions/voice). Because it remembers, you can tell it how you like to work, what to call you, or what to keep an eye on, and it will keep that in its own memory. See [Memory](/agents-that-stay/memory).

Agents shine when you hand them bigger jobs: they can start other sessions, check on them and report back. See [Orchestration](/orchestration).
