---
title: Keyboard shortcuts
description: The keys that work across supermux, with Ctrl on Windows and Linux and ⌘ on a Mac.
---

Wherever a shortcut uses <Kbd>Ctrl</Kbd>, use <Kbd>⌘</Kbd> on a Mac.

## Everywhere

| Keys | What it does |
|---|---|
| <Kbd>Ctrl</Kbd> <Kbd>N</Kbd> | Start a new session |
| <Kbd>Ctrl</Kbd> <Kbd>T</Kbd> | Open a terminal in the current workspace |
| <Kbd>Ctrl</Kbd> <Kbd>B</Kbd> | Show or hide the sidebar |
| <Kbd>Ctrl</Kbd> <Kbd>Shift</Kbd> <Kbd>N</Kbd> | Move to a new window |
| <Kbd>Esc</Kbd> | Close the launcher |

## Composer

| Keys | What it does |
|---|---|
| <Kbd>Enter</Kbd> | Send |
| <Kbd>Shift</Kbd> <Kbd>Enter</Kbd> | New line |
| Hold <Kbd>Space</Kbd> | Dictate while held |
| <Kbd>Ctrl</Kbd> <Kbd>V</Kbd> | Paste an image |
| <Kbd>↑</Kbd> <Kbd>↓</Kbd>, <Kbd>Enter</Kbd> or <Kbd>Tab</Kbd>, <Kbd>Esc</Kbd> | Move, pick and close in the `/` and `@` menus |

## Chat

| Keys | What it does |
|---|---|
| <Kbd>Ctrl</Kbd> <Kbd>F</Kbd> | Find in the chat |
| <Kbd>Enter</Kbd> / <Kbd>Shift</Kbd> <Kbd>Enter</Kbd> | Older / newer match |
| <Kbd>←</Kbd> <Kbd>→</Kbd>, <Kbd>Space</Kbd>, <Kbd>F</Kbd>, <Kbd>Esc</Kbd> | In the media viewer: previous and next, play and pause, full screen, close |

## Files and editor

| Keys | What it does |
|---|---|
| <Kbd>Ctrl</Kbd> <Kbd>P</Kbd> | Go to file |
| <Kbd>Ctrl</Kbd> <Kbd>S</Kbd> | Save |
| <Kbd>Ctrl</Kbd> <Kbd>F</Kbd> | Find in the file |
| <Kbd>Ctrl</Kbd> <Kbd>D</Kbd> | Select the next match too |
| <Kbd>Ctrl</Kbd> <Kbd>/</Kbd> | Comment or uncomment |
| <Kbd>Alt</Kbd> <Kbd>↑</Kbd> <Kbd>↓</Kbd> | Move the line up or down |
| <Kbd>Ctrl</Kbd> <Kbd>Space</Kbd> | Show completions (on a Mac, also <Kbd>⌥</Kbd> <Kbd>I</Kbd>) |
| <Kbd>F12</Kbd> / <Kbd>Shift</Kbd> <Kbd>F12</Kbd> | Go to definition / find references |
| <Kbd>F2</Kbd> | Rename (a symbol in the editor, a file in the tree) |
| <Kbd>F7</Kbd> / <Kbd>Shift</Kbd> <Kbd>F7</Kbd> | Next / previous change, in the Changes view |

## Terminal

| Keys | What it does |
|---|---|
| <Kbd>Ctrl</Kbd> <Kbd>Shift</Kbd> <Kbd>C</Kbd> / <Kbd>V</Kbd> | Copy / paste (<Kbd>⌘</Kbd> <Kbd>C</Kbd> / <Kbd>V</Kbd> on a Mac) |
| <Kbd>Ctrl</Kbd> <Kbd>Shift</Kbd> <Kbd>F</Kbd> | Find |
| <Kbd>Ctrl</Kbd> <Kbd>=</Kbd> / <Kbd>-</Kbd> / <Kbd>0</Kbd> | Bigger, smaller, reset the text size |
