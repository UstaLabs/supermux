API
  session.updateContext(patch: {
    instructions?: string | string[]          // replaces the session's own instructions
    skills?: { add?: string[]; remove?: string[] }
    plugins?: { add?: string[]; remove?: string[] }
    mcpServers?: { add?: ExternalMcpServer[]; remove?: string[] }  // remove by name
  }, options?: { reload?: "allow" | "never"; holdOnCacheImpact?: boolean })
  → Promise<{ applied: Array<{ kind, item, how: "live" | "reload" | "append" | "unsupported", reason? }>,
              effective: "now" | "next_turn" }>
  plus an event { type: "context.updated", sessionId, applied } on the session stream.
Also core.sessions.updateContext(id, patch, options) for a session that isn't open (it only updates
the record; the next launch applies it).

Semantics
- Validate like C1 (invalid_context). The patch applies to the session's OWN context; the core
  default is untouched. Persist the new context to the record before any change goes out to the
  agent, so a crash never leaves the record older than what is live.
- Decide per item from the driver's declared capabilities: live when proven, otherwise reload (if
  allowed), otherwise unsupported. Under the session's contextPolicy "error", if anything would be
  unsupported, apply NOTHING and throw context_unsupported. Under "warn", apply what can be applied
  and report the rest.
- If any item needs a reload: never cancel a running turn. Wait until idle (the same rule as
  auto-switch), then relaunch on the same conversation with the full new context; queued input runs
  after. reload: "never" → those items are unsupported. Live items go out immediately, even
  mid-turn when the mechanism allows it; otherwise at the next idle point. Report `effective`
  truthfully.
- Instructions: Claude → reload. OpenCode → reload. Codex → cannot replace. With option
  `codexInstructions: "append"`, send via turn/start.additionalContext on later turns (C0 proved
  it; it lands in history, so make it opt-in). Without that option it is unsupported. Grok →
  unsupported.
